# Competition Engine

## Fluxo
`Eligibility → Draw → Stages → Matches → Standings → Qualification`

## Sorteio
Tipos:
- `RANDOM`
- `MANUAL`
- `SEEDED`
- `POTS`

Sorteio confirmado fica bloqueado; reabertura deve ser auditável.

## Formatos
- `ROUND_ROBIN`
- `GROUP_STAGE`
- `KNOCKOUT`
- `GROUPS_PLUS_CUPS`
- `SWISS`

## Ouro/Prata/Bronze
Uma fase classificatória pode gerar ramificações. Uma equipe não pode participar de duas ramificações derivadas da mesma fase.

## Suíço
- número fixo de rodadas;
- pareamento por desempenho;
- evitar revanche;
- suportar bye;
- não repetir bye antes das demais equipes quando possível;
- Buchholz opcional.

## Pontuação padrão
- vitória: 3
- empate: 1
- derrota: 0

## Desempate padrão
1. pontos
2. saldo de gols
3. gols marcados
4. confronto direto
5. menos vermelhos
6. menos amarelos
7. sorteio

## Resultados
Resultado finalizado atualiza classificação, estatísticas e progressão.

## WO
Placar configurável; atualiza classificação; não gera gols individuais por padrão.
